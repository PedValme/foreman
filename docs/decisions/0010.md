# 0010 · `foreman-gate` as the package name, `foreman` as the command

**Decision.** Wherever the adapters are installed as a package (npm and the registries built on it, plugin
marketplaces), the name is `foreman-gate`, from this one repository. `foreman` stays where it is the name in use: the
command `/foreman`, the plugin's name inside Claude Code, OpenCode's plugin id and the Hermes catalog entry.

**Why.** On npm, `foreman` (and `opencode-foreman`) are other projects' packages. Inside Claude Code the plugin's name
is the prefix of the person's commands, so `foreman` gives `/foreman:status`.

**Alternatives.** A different name per store (one product under several names). Renaming the command too (breaks what
Hermes users already type).
