# 0007 · In Hermes, the reviewer is an auxiliary task

**Decision.** Foreman registers its review as one of Hermes's auxiliary tasks, "Foreman review". It is picked in
Hermes's own model pickers (`hermes model` → Configure auxiliary models, the dashboard's Models page, Desktop's
Settings → Models → Auxiliary), from the providers and models the user already configured. Its default is the first
fallback model.

**Why.** Picking the reviewer should be a dropdown of what is already configured, in the place a Hermes user already
picks models, and calling another model should need no override capability.

**Alternatives.** A model picker drawn by Foreman in its own panel: a plugin cannot write Hermes's auxiliary choice, so
it would need a second place where models are configured. A model named in Foreman's own settings file: no dropdown,
and easy to point at a model that is not configured.

**Consequences.** A native picker inside Foreman's panel needs a seam Hermes does not offer yet.
