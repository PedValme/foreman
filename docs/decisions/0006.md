# 0006 · Where a skip marker counts

**Decision.** In test files a skip marker counts wherever it appears. Outside them it counts only when written as
code: one inside a quoted string or a comment does not switch a test off. Two exceptions keep the gap closed: a skip
helper defined as code outside the tests (a module-level skip mark bound to a name) still counts, and in the files
that run the check (CI workflows, Makefile, tox, nox, `package.json`…) a quoted marker counts too, because a command
there can write a skip into the tests. In Python files `//` is not a comment.

**Why.** Reading every occurrence anywhere reported Foreman's own detector (its regular expressions name the markers)
and a shell script that only quoted one as skipped tests. Reading only test files would let a skip helper defined
elsewhere through.

**Alternatives.** Markers counted only in test files (misses a helper defined outside them). Markers counted
everywhere (false refusals on any code that names a marker, starting with Foreman's own).

**Consequences.** Foreman's own sources and tests never write a marker literally; fixtures build it from parts.
