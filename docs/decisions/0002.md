# 0002 · One slash command, `/foreman`

**Decision.** Everything a person does with Foreman lives under one slash command, `/foreman`, with subcommands
(`status`, `review`, `merge`, `reject`, `allow`, `pipeline`, `use`, `notify`…). No other slash command is registered,
and none shadows one of Hermes's own (`/review`, `/branch`, `/diff`, `/status`, `/approve`…).

**Why.** Hermes rejects a plugin command whose name collides with a native one without telling the user, and every
new top-level name is one more chance of a collision with Hermes or with another plugin. One name is also one thing
for a person to remember.

**Alternatives.** A command per action (`/merge`, `/gate`…): several collide with Hermes's own names, and the rest
could collide with names Hermes adds later.

**Consequences.** Outside Hermes the same subcommands are plugin commands of each harness (in Claude Code,
`/foreman:status`), because Claude Code's prompt rejects an unknown `/foreman` before any hook sees it. See
`docs/rules.md`, rule 5.
