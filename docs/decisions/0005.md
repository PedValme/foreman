# 0005 · Only `plugin/` is installed

**Decision.** The Hermes plugin is the `plugin/` folder (the catalog entry says `subdir: plugin`): its manifest,
registration, the `foreman/` package, the Desktop and dashboard files, its README and its licence. Nothing in it reads
outside `plugin/`. Tests, examples, adapters and documentation stay at the repository's root.

**Why.** A user's install should carry only the code that runs, nothing a developer of Foreman needs. Keeping
`plugin/` self-contained also makes it the single source the adapters import (0008) without the plugin knowing about
them.

**Alternatives.** The plugin at the repository's root: every install would copy the tests, examples and documents to
the user's machine.

**Consequences.** The repository's root is also the package other harnesses install, so nothing binary, generated or
private is committed anywhere in it. See `docs/rules.md`, rules 21 and 22.
